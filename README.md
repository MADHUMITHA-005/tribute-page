# Sundar Pichai Tribute Page

My first web development project, created using HTML to build a tribute page dedicated to Sundar Pichai, CEO of Google.

## About the Project

This project was created to practice the fundamentals of HTML and learn how to structure a webpage. It presents a tribute to Sundar Pichai and introduces his life and achievements.

## Technologies Used

* HTML5

## What I Learned

* Creating a webpage using HTML.
* Using headings, paragraphs, and images.
* Organizing content into structured sections.
* Understanding the basics of web development.

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open the HTML file in your browser.
